# Towhid Karim – Portfolio

A modern, dynamic, and responsive personal portfolio showcasing my projects, experience, and skills. Built with **Next.js**, powered by **Turso** and **Redis** for fast and efficient project fetching, and supported by a dedicated backend for managing projects and messages.

## 🚀 Features

- **Dynamic Project Showcase**  
  Projects are not hardcoded! They are stored on **Turso** and fetched from **Redis** cache for optimal performance and scalability.

- **Backend Integration**  
  Includes a custom backend for:
  - Managing projects (CRUD operations)
  - Handling messages from the contact form

- **Responsive Design**  
  Fully responsive and mobile-friendly for a seamless user experience.

- **SEO Optimized**  
  Optimized meta tags and structured data for better search engine visibility.

- **Deployed on Vercel**  
  Ensuring high availability and performance with serverless deployment.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (React), TypeScript, Tailwind CSS, Shadcn UI
- **Backend:** Next.js
- **Database / Cache:** Redis, Turso, Drizzle
- **Deployment:** Vercel
