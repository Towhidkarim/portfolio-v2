Reveal systemYour component, refined

A curtain that gets out of the way.

Reveal keeps its idea, a block sweeping across to uncover content, and gives it a job: marking the few moments that define the page. Everything else rises quietly or stays still.

02Anatomy

The curtain, phase by phase

0 to 450 ms
Cover
Teal block scales in from the left. Content is still hidden.
450 to 900 ms
Uncover
Content swaps at full cover, block exits to the right.
After
Settle
Block is gone; text is plain and selectable.
Easing is cubic-bezier(.7, 0, .2, 1) on each half. Only transform and opacity animate, so the work stays on the compositor. With reduced motion the block is removed and the content fades in over 150 ms.

05Code

What ships

// reveal.tsx: server-renderable, no client JS
export function Reveal({ as: Tag = 'div', variant = 'rise', delay = 0, ...p }) {
  return <Tag data-reveal={variant} style={{ '--d': `${delay}s` }} {...p} />
}

// reveal.css
@media (prefers-reduced-motion: no-preference) {
  html.js [data-reveal=rise]:not([data-in]) { opacity: 0; transform: translateY(12px) }
  [data-reveal=rise][data-in] { transition: opacity .7s, transform .7s cubic-bezier(.2,.7,.2,1); transition-delay: var(--d) }
  [data-reveal=curtain][data-in]::after { animation: cwipe .9s var(--d) both }
}

// reveal.js, inlined in <head>, about 400 bytes
document.documentElement.classList.add('js')
const io = new IntersectionObserver((es) => es.forEach((e) => {
  if (e.isIntersecting) { e.target.setAttribute('data-in', ''); io.unobserve(e.target) }
}), { rootMargin: '0px 0px -12% 0px' })
document.querySelectorAll('[data-reveal]').forEach((el) => io.observe(el))
