# Pending research register

Everything here could not be verified when the plan was written (2026-10-09). The planning sandbox blocked `tanstack.com`, `developers.cloudflare.com` and most other doc sites, so facts came from web search summaries and the npm registry.

How to use this file:

1. Before a phase's dependent step, find the R-id the step cites.
2. Resolve it from the **current official docs** or by running the spike in the "How to verify" column.
3. Write what you found in the **Resolution** column (one or two lines, with the doc URL and the date) and update the spec files that cited it.
4. If you cannot reach the docs either, implement the **Fallback**, leave the Resolution as `UNRESOLVED (reason)`, and flag it in your handoff.

Status values: `open`, `resolved`, `unresolved`.
